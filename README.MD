# 🎬 4ces Clipfinder

Der **4ces Clipfinder** ist ein kostenloses, portables Windows-Tool für Streamer und Video-Cutter. Es analysiert Twitch-VODs und lokale Mediendateien automatisch auf laute Geräusche und Schlüsselwörter, um Highlight-Zeitstempel zu erstellen.

## ✨ Features
* **Twitch-Link Support:** Füge einfach einen Twitch-VOD-Link ein – das Tool lädt nur die Tonspur herunter und spart Speicherplatz.
* **Lokale Dateien:** Verarbeitet `.mp4`, `.mp3`, `.wav`, `.m4a` u.v.m.
* **Lautstärke-Peak-Erkennung:** Findet laute Momente (Lachen, Schreie, Rages).
* **KI-Transkription (OpenAI Whisper):** Durchsucht die Sprachspur gezielt nach Keywords (`clutch`, `krass`, `bruder` etc.).
* **Cooldown-Filter:** Verhindert doppelte Zeitstempel in kurzen Abständen.
* **Text-Export:** Speichert alle Funde übersichtlich in einer `.txt`-Datei mit präzisen Zeitstempeln.

## 📥 Download & Nutzung
1. Gehe rechts auf **Releases**.
2. Lade die neuesten `zip files` herunter.(im gleichen Ordner )
3. entpacke die 1. Datei die 2. sollte dann automatisch mit entpackt werden
4. Starte die Anwendung per Doppelklick (keine weitere Installation erforderlich).
